# 離線序列素材

`scripts/render-scene.html` 包含原創 Three.js 場景，不是網站執行期的一部分。立體檔案貼圖來自本專案已有作品封面與簡報頁面。core 使用三個互相穿插的立體環、中央核心與軌道節點；archive 使用五張有厚度的卡片和真實作品貼圖。

## 重新渲染

在專案根目錄執行：

```sh
npm install --prefix tools/renderer
cd tools/renderer
npx playwright install chromium
cd ../..
node scripts/render-sequences.cjs
```

可傳入 `core` 或 `archive` 只重建該組。也可透過環境變數 `CHROME_PATH` 指定本機 Chromium/Chrome 可執行檔。Chrome 僅做離線圖像渲染；不連到使用者瀏覽器資料或既有分頁。程式使用 CPU 軟體 WebGL，避免需要實體顯示器。

輸出：`public/sequences/{core,archive}/000.webp` 至 `143.webp` 及各自的 `mobile` 子目錄。桌面使用 1200px，手機使用 600px。`manifest.json` 記錄數量和尺寸。每張圖片對應一個連續場景狀態，並非換頁幻燈片。

分享圖 `public/og.png` 為原創 AI 生成作品；不包含私人聯絡資料。網頁內容與實際簡報保留原始作者和引用註記。
