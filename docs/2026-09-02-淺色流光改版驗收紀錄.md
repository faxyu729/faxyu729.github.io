# 淺色流光檔案館驗收紀錄

## 交付範圍

范芯瑜個人作品集，React 19、Vite 6、Tailwind 4，新增 GSAP ScrollTrigger；既有 Framer Motion 用於局部互動。採霧白／冰藍／淡紫配色。保留三份作品、PDF 與聯絡資訊。沒有複製 Apple 版型、產品圖或商標。

## 元素對照

| 類別 | 實作 | 數量 |
|---|---|---|
| 真實連續影格 | core 旋轉展開、archive 立體檔案分層 | 2 組，各 144 張 |
| 釘選時間軸 | home、observation、archive、works（桌面） | 4 段 |
| 遮罩轉場 | about 圓形揭露、works 光幕擦除 | 2 處 |
| 彈簧互動 | 三張作品詳情展開／收合、三張聯絡卡片 hover/tap | 2 套 |
| 玻璃深度 | 導覽列、拆解說明卡片、聯絡卡片 | 3 處 |

可辨識滾動互動：核心逐格旋轉、首頁字幕交棒、首頁光場旋轉、圓形遮罩、關於文字逐句點亮、背景視差、圖線繪製、節點展開、觀測步驟入場、檔案逐格拆解、說明卡片錯開入場、桌面展廊橫移、展廊光幕、聯絡光線匯聚、聯絡卡片入場。

## 已實際檢查

- 桌面 1440×900、行動版 390×844 預覽。
- 首頁逐格進度到達 108，反向回到 0；停止操作後停留於相應影格。
- 拆解序列進度到達 60；後續調整鏡頭為正面擺動，避免背面遮蔽作品。
- 章節導航可跳轉，手機選單可展開並在選取後收合。
- 作品詳情按鈕可展開，aria-expanded 狀態跟隨更新。
- 動態關閉後 Canvas 數量為 0，四個場景皆解除 sticky 和長捲動距離。
- 手機 document scrollWidth 與 clientWidth 相同，無頁面橫向溢出。
- 預覽瀏覽器未捕獲 JavaScript error/warn。

## 素材與效能策略

桌面每組 144 張 1200×1200 WebP，手機每組 144 張 600×600 WebP；兩組、兩種尺寸合計 576 個影像檔。素材只由本機供應，無圖片 CDN。WebGL 僅用於离線產生素材，訪客瀏覽時使用 2D Canvas。

每次最多 3 個載入請求；優先目標影格，再載入前後 5 格。解碼快取上限為桌面 18 格、手機 12 格；離開附近視野時縮至 1 格並中止請求。缺圖顯示最近已解碼影格；沒有可用影格時保留海報。系統減少動態偏好會預設關閉動態；使用者亦可直接切換。

## 驗收界限

本次以目前可用的 Chromium 桌面預覽與模擬手機尺寸驗收；沒有宣稱完成 Safari、實體 iPhone 或低階手機的效能測試。尚未量測全裝置 FPS 或 Core Web Vitals。斷線備援邏輯與影格映射有程式測試，未進行完整瀏覽器網路中斷注入測試。

此版本在使用者指定遠端電腦的私人網路預覽，不另行公開發布。Open Graph 圖片 URL 使用該預覽地址，日後公開部署時須改成正式網域。
