# 流光檔案館：淺色沉浸式作品集規格

本版依 2026-09-02 使用者指示，取代原「簡約風」配色與互動限制。原規格保存在「舊版簡約個人網站規格.md」，不再作為本版的視覺或動畫限制。

## 視覺

霧白 #f8fafc、冰藍 #e8f1ff、淡紫 #ece5f7；正文墨藍 #1b2b43。以滿版立體序列、流動光影、大字和玻璃浮層呈現內容，介面保持繁體中文。

## 場景

1. 首頁：立體核心逐格旋轉、文字交棒、光場旋轉。
2. 關於：圓形遮罩穿越、逐句點亮、背景視差。
3. 系統觀測：釘選畫面、圖線描繪、節點與步驟編排。
4. 檔案拆解：144 張立體檔案影格、錯開入場的說明卡片。
5. 精選作品：桌面橫向滾動展廊、手機直向卡片、光幕擦除、彈簧詳情。
6. 聯絡：光線匯聚、卡片入場、彈簧按壓與原始聯絡連結。

## 技術與素材

沿用 React 19、Vite 6、Tailwind 4。GSAP 控制滾動時間軸；Framer Motion 控制卡片互動，避免重疊控制同一層 transform。兩組序列共 288 張連續影格，各有桌面和手機版本。採 Canvas 2D、鄰近預載、有限解碼快取、離屏釋放和海報備援。

保留原有 node:test 測試，新增影格映射與素材完整性測試。離線 Three.js 素材工具隔離在 tools/renderer，不打包進訪客頁面。

## 可用性

保留三份作品的 PDF、聯絡資訊、章節錨點、可見鍵盤焦點、跳至內容連結。手機為直向作品展廊。尊重 prefers-reduced-motion，並提供手動動態開關；關閉時解除長段釘選、直接顯示所有內容。
