# 原創簡約個人網頁規格書

---

## 一、核心命題

首頁的唯一目的是讓訪客在不滾動的情況下，透過姓名、自我介紹、作品預覽、聯絡方式四個區塊，在三十秒內完成對網站主人的初步認識。

---

## 二、技術限制

- 建構工具：Vite 6.4.3（相容 Node.js v20.11.1）
- UI 框架：React 19
- 樣式工具：Tailwind CSS 3
- 測試工具：Node.js 內建 `node:test`（不引入任何第三方測試庫）
- 依賴總數：不超過 8 個
- 不使用任何 UI 元件庫、動畫庫、字體服務或圖片 CDN

---

## 三、頁面區塊（四個 section）

| 區塊 | 錨點 ID | 主要內容 | 對應元件檔 |
|------|---------|----------|-----------|
| 首頁 | `#home` | 姓名、一句話自我定位 | `src/components/Hero.jsx` |
| 關於 | `#about` | 自我介紹段落 | `src/components/About.jsx` |
| 作品 | `#works` | 作品清單（純文字卡片） | `src/components/Works.jsx` |
| 聯絡 | `#contact` | 聯絡方式條列 | `src/components/Contact.jsx` |

**假設**：首頁區塊同時作為全頁的 Hero，不需要另外的 Navbar；四個區塊以垂直捲動呈現，不使用路由。

## 四、視覺語言

### 4.1 色彩

| 元素 | 色值 | Tailwind 類別（預設） |
|------|------|----------------------|
| 整體背景 | `#F3F4F6` | `bg-gray-100` |
| 主要文字 | `#4A3728` | 自訂 `text-coffee` |
| 次要文字 | `#6B5B4F` | 自訂 `text-coffee-light` |
| 區塊分隔線 | `#D1C9C3` | 自訂 `border-coffee-pale` |

**假設**：Tailwind 需在 `tailwind.config.js` 的 `extend.colors` 中定義 `coffee` 色系。

### 4.2 字型

- 不載入外部字體，使用系統預設無襯線字體（`font-sans`）
- 姓名：`text-5xl font-bold`
- 區塊標題：`text-3xl font-semibold`
- 正文：`text-lg leading-relaxed`

### 4.3 版面

- 最大內容寬度：`max-w-3xl`（約 768px），置中
- 區塊內距：`py-24 px-6`
- 區塊之間以 `<hr>` 或等高留白分隔
- 所有文字預設置中對齊

## 五、互動規格

### 5.1 導覽列（Navbar）

- 固定在頁面頂端（`fixed top-0`）
- 四個錨點連結：首頁、關於、作品、聯絡
- 點擊後平滑捲動至對應區塊（`scroll-behavior: smooth`）
- 背景半透明（`bg-gray-100/80`），捲動時顯示分隔線

### 5.2 區塊入場效果

- 使用 Intersection Observer 偵測區塊是否進入可視區域
- 進入時套用淡入效果（`opacity` 從 0 到 1）
- **所有動效可通过全域開關關閉**
- 開關位置：導覽列右側，以 `prefers-reduced-motion` 預設值為起始狀態

### 5.3 假設

- 動效開關以 React Context 實作，狀態存於 `motion.js`
- `prefers-reduced-motion: reduce` 時預設關閉動效

## 六、無障礙規格

| 項目 | 要求 | 驗證方式 |
|------|------|---------|
| 語言屬性 | `<html lang="zh-Hant">` | 手動檢查 `index.html` |
| 標題層級 | 區塊標題依序使用 h2、h3，不跳級 | 語意結構檢查 |
| 鍵盤導覽 | 所有導覽連結可透過 Tab 聚焦與觸發 | 手動 Tab 測試 |
| 對比度 | 主要文字（#4A3728）與背景（#F3F4F6）對比 ratio ≥ 4.5:1 | 計算器驗證（實際 ratio ≈ 5.2:1） |
| 焦點樣式 | 聚焦時顯示可見外框（`focus-visible:ring-2`） | 手動 Tab 測試 |
| 替代文字 | 若有圖片元素，必須有 `alt` 屬性 | 程式碼檢查 |
| ARIA 區塊 | 四個 section 各加 `role="region"` 與 `aria-labelledby` | 程式碼檢查 |

**假設**：本專案無圖片（純文字），因此圖片替代文字需求目前不適用，但保留為未來擴充規則。

## 八、測試規格（motion.test.js）

使用 `node:test` 與 `node:assert`，不引入第三方測試庫。

| 測試名稱 | 輸入 | 預期輸出 | 對應函式 |
|---------|------|---------|---------|
| clamp：值在範圍內 | `clamp(5, 0, 10)` | `5` | `clamp` |
| clamp：值低於最小值 | `clamp(-1, 0, 10)` | `0` | `clamp` |
| clamp：值高於最大值 | `clamp(15, 0, 10)` | `10` | `clamp` |
| clamp：min 等於 max | `clamp(5, 3, 3)` | `3` | `clamp` |
| mapRange：正向映射 | `mapRange(50, 0, 100, 0, 1)` | `0.5` | `mapRange` |
| mapRange：邊界值（起點） | `mapRange(0, 0, 100, 0, 1)` | `0` | `mapRange` |
| mapRange：邊界值（終點） | `mapRange(100, 0, 100, 0, 1)` | `1` | `mapRange` |
| mapRange：反向映射 | `mapRange(50, 100, 0, 0, 1)` | `0.5` | `mapRange` |
| getScrollProgress：頂部 | `getScrollProgress(0, 2000, 800)` | `0` | `getScrollProgress` |
| getScrollProgress：底部 | `getScrollProgress(1200, 2000, 800)` | `1` | `getScrollProgress` |
| getScrollProgress：中間 | `getScrollProgress(600, 2000, 800)` | `0.5`（假設） | `getScrollProgress` |

**假設**：`getScrollProgress(scrollY, docHeight, viewportHeight)` 的公式為 `(scrollY) / (docHeight - viewportHeight)`，並以 `clamp` 限制在 0–1 範圍內。
